## Reproducible structural and provenance verification

The current repository-local entry point is `python3 tools/validate_research.py --write`, run from the research repository root. The following describes the historical validation scope. It checks all expected reports, all 24 feature IDs and verdicts per report, assessment revision/date, current Git HEAD/status against the baseline, the checkout inventory, all 25 audit files, and local links in reports and supporting Markdown. It records SHA-256 report digests and regenerates the combined feature matrix.

The validator does not prove arbitrary prose claims, execute any alternative, or establish operational reliability. Those semantic judgments are supported by the per-report source evidence and independent audits, whose coverage and limitations are explicit. The final validation must pass after this audit and the final report changes are saved.
