### Corrections and important boundaries

Final recheck: the F02 matrix and F19 citation corrections below were incorporated into the report during this audit. They are retained as the audit trail; neither is an outstanding correction.

1. **F02 matrix wording must agree with the default modular-prompt finding.** The legacy path prepends the stored member `systemPrompt` at [agent-registration.service.ts](../../../crewly/repo/backend/src/services/agent/agent-registration.service.ts), lines 2726-2743. Therefore the F02 sentence that unqualified member prompt injection supplies specialization should identify this as the legacy path. The lifecycle section already describes the mismatch correctly. Structured job, soul, ownership and skill fields still support specialization; this is a propagation caveat, not evidence that every agent is identical.

2. **F11 deserves credit for actual collaboration, but normal agent replies do not automatically fan out.** [chat-v2.controller.ts](../../../crewly/repo/backend/src/controllers/chat-v2/chat-v2.controller.ts), lines 945-977, dispatches only `senderType === 'user'`. [chat-v2.dispatcher.service.ts](../../../crewly/repo/backend/src/services/chat-v2/chat-v2.dispatcher.service.ts), lines 1243-1267, expressly skips other rows. Actual cross-channel agent delivery is possible because [chat-v2.service.ts](../../../crewly/repo/backend/src/services/chat-v2/chat-v2.service.ts), lines 2013-2034, resolves an agent posting into a different bound channel as a user-origin row while preserving agent provenance. Private colleague handoffs are separately implemented at controller lines 410-438. An Exact verdict for rooms/direct collaboration is defensible only with those boundaries, not an assumption that every visible reply wakes all room members. The updated coordination paragraph acknowledges separate private delivery.

3. **F19 citation correction only.** `BoardTimelineEvent` is at [board.types.ts](../../../crewly/repo/backend/src/services/board/board.types.ts), lines 92-98, rather than 100-106. It contains session/time/type/text and no task/chat/artifact reference fields. [board-activity.tracker.ts](../../../crewly/repo/backend/src/services/board/board-activity.tracker.ts), lines 1-8 and 61-68, explicitly uses process-local rolling maps. The report's Resembles verdict and durability limitation are correct.
