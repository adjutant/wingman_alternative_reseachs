## Gas Town: full report reviewed and network primitive correction incorporated

The report was absent on initial inventory; it subsequently appeared and was read in full. Source-first checks sent the following boundaries to the author/root:

1. **F17 managed remote execution remains incomplete:** `internal/connection/registry.go:168–182` returns a local connection, but the `ssh` case explicitly errors with “ssh connections not yet implemented.” A machine registry/interface is not working multi-host agent execution. See the network bridge correction below before assigning the final row verdict.
2. **Do not erase implemented federation:** `internal/wasteland/wasteland.go:1–7,99–165,169–252,315–374` implements DoltHub fork/clone/upstream registration/commit/push and join state. This is substantial work federation, distinct from remote worker dispatch. `docs/why-these-features.md:153–155` is stale when it calls federation wholly planned; implementation takes precedence.
3. **F11 deserves retained channel credit:** `internal/mail/types.go:96–119,192–205` models reply threads and direct/queue/channel messages. `internal/mail/router.go:879–881` dispatches `channel:` addresses to retained broadcast handling. `internal/cmd/mail_directory.go` exposes agents/groups/queues/channels, and `internal/cmd/mail_announce.go:104–185` reads channel history. 4. **F19 is not wholly absent:** `internal/cmd/audit.go:30–70,89–144` collects actor-filtered git, beads, townlog and feed events into readable chronological summaries with source IDs. It is useful linked provenance; it does not independently establish a synthesized employee executive timeline.

Preserve useful visibility but do not relabel it as current/recent/next per-agent product progress.
