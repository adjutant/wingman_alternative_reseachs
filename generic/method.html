Assessment method and evidence

Scope

The active orchestration study contains 49 source assessments. Each assessment uses one pinned local checkout. The common baseline is Wingman's purpose. The original source review date is November 5, 2026. The report reorganization started on November 6, 2026.

The reports assess source behavior. They do not certify a current upstream release or a production deployment. No candidate repository was updated during reorganization. The Wingman application folders main/ and newman/ remain outside this review.

Review path

  1. Record the repository URL, full commit, and Git status.
  2. Read applicable checkout instructions.
  3. Locate the executable entry point and state owner.
  4. Trace agent creation, identity, tools, permissions, and execution.
  5. Trace one request through routing, persistence, worker activity, and completion.
  6. Inspect concurrency, interruption, retries, recovery, and cleanup.
  7. Compare all 24 Wingman features with cited implementation evidence.
  8. Describe substantial extra capabilities and their integration cost.
  9. State tests inspected, tests run, missing source, and unverified runtime behavior.

Use targeted searches for an absent feature. State the code areas searched. A missing README section is insufficient evidence for an Absent verdict. An externally hosted implementation can require an Unclear verdict.

Verdicts

Verdict Meaning
Exact The inspected behavior meets the stated feature within the report's boundary.
Similar A substantial equivalent exists. Its workflow, scope, or persistence differs.
Resembles A related mechanism exists. It does not supply the complete feature.
Absent Targeted source searches found no corresponding implementation.
Unclear Missing source or an external dependency prevents a reliable finding.

Do not sum these labels into a maturity score. A workflow compiler, a workbench, and an organization service solve different problems. Read the evidence beside each label before using it for a design decision.

Evidence levels

Level What it supports Limit
Source traced A concrete implementation path at the pinned commit Deployment configuration can change observed behavior.
Test inspected The assertion and its intended contract The test was not necessarily executed.
Isolated test executed The named contract in the recorded environment It does not establish a complete deployed agent organization.
Documentation inspected The documented interface or hosted behavior at the recorded date It can differ from the local implementation or later releases.
Proposed design A possible Wingman contract or experiment It is not an observed candidate capability.

The 25 historical audit records are in the audit folder. They record independent source checks from the original assessment work. Their document hashes are historical. Use current validation records for current file hashes.

Historical host paths can be normalized when the change is disclosed with original and current hashes. Call these files path-normalized historical evidence. Do not call them unchanged raw logs or new test runs. See the portability audit for the transformation record.

Writing review

Use ASD-STE100 principles for authored assessments and reports. Use short sentences, active voice, one topic per sentence, and consistent terminology. Preserve API names, state names, code paths, and necessary technical terms. Explain a technical term at its first use when the reader needs that definition. Avoid a formal compliance claim without a controlled-vocabulary review.

A sentence-length check can locate difficult prose. It cannot establish active voice or technical accuracy. Source findings and experiment outcomes retain their original meaning. Disclosed path normalization does not establish a new observation. The report review must distinguish those records from authored explanations.

Report design

The reports share one stylesheet and one script. They use the supplied Manrope fonts, navy navigation, pale surfaces, red accents, and compact tables. Project detail uses readable technical prose and evidence links. The overview uses high-impact findings and a filterable comparison table. All report content remains available without network access or JavaScript.
